# Ảnh chụp bằng chứng khảo sát

Mỗi thành viên chụp màn hình trang giá và trang tính năng của hệ thống mình khảo sát,
lưu vào thư mục này theo tên `<tên-sản-phẩm>-<mục>.png`.

Ví dụ: `veed-pricing.png`, `veed-subtitle-feature.png`, `kapwing-pricing.png`.

Danh sách hệ thống và kết luận so sánh nằm ở [../DAC_TA_YEU_CAU.md §2](../DAC_TA_YEU_CAU.md#2-kết-quả-khảo-sát).

Giá dịch vụ thay đổi thường xuyên — chụp lại ngay trước khi nộp và ghi ngày truy cập.
